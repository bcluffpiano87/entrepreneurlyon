# Partner Updates

## What This Produces

A formatted section presenting 3-5 bullet points from each partner organization on what they are working on, upcoming events, or news relevant to the community. The content comes from the partners -- this section formats, it does not editorialize.

## Inputs Required

- **Partner raw text:** for each partner, the editor provides the raw update they received (email, message, or notes from a call). Expected partners:
  - FIBA Lyon (Franco-International Business Association)
  - ONLYLYON
  - One rotating "networking partner" (varies monthly -- could be CCI, a coworking space, an incubator, etc.)

## Output Format

```
### FIBA Lyon

- [Bullet point 1: formatted from raw input]
- [Bullet point 2]
- [Bullet point 3]

### ONLYLYON

- [Bullet point 1]
- [Bullet point 2]

### [Rotating Partner Name]

- [Bullet point 1]
- [Bullet point 2]
```

## Formatting Rules

- Rewrite the raw text into clean, concise bullet points -- fix grammar, remove filler, standardize date formats
- Preserve the partner's meaning exactly -- do not add interpretation, commentary, or editorial spin
- If a partner mentions an event, include the date and a link if one was provided
- If a partner provided nothing this month, omit that partner entirely -- do not write "No update this month"

## Tone

- Neutral, informational -- this is the partner's voice, not the newsletter's
- Do not praise or critique the partner's activities
- Do not add "we're excited to share" or similar editorial framing

## Constraints

- Plain ASCII text only
- Do not fabricate partner updates -- use only what the editor provides
- Do not add links the partner did not provide
- 3-5 bullets per partner, max 30 words per bullet
- If only one partner provided an update, publish only that one
