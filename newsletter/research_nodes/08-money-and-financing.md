# Money and Financing

## What This Produces

A focused section on one category of funding, financial support, or tax advantage available to international entrepreneurs in Lyon. Rotates through categories monthly so the newsletter covers the full landscape over time.

## Inputs Required

- **Rotating category for this month:** selected by the editor from the rotation list. Categories:
  - Interest-free loans (prets d'honneur)
  - Government grants and subsidies
  - Tax credits (CIR, CII, JEI, IP Box)
  - Micro-entrepreneur specific finance
  - International / foreign entrepreneur specific (residence permits, SINGA, French Tech Tremplin)
  - Crowdfunding and alternative finance (revenue-based, angel networks)
  - Banking and practical finance (droit au compte, online banks, common pitfalls)
  - Coworking and pepinieres with financial perks
- **Previously used categories:** from the Newsletter Pipeline file (no immediate repeats; full cycle before reuse)

## Source Material

The primary source is the funding database: 
ewsletter/ENTREPRENEUR_LYON_FUNDING_SOURCES.md. This file contains verified, sourced entries with pre-written newsletter blurbs for each item.

## Production Process

1. Read the funding database section for the selected category
2. Select 2-4 items from that category that are most relevant to the community
3. Re-verify key facts via web search: amounts, deadlines, eligibility, contact information
4. If any fact has changed since the database was last updated, use the updated figure and flag the change
5. Write the section using the pre-written blurbs as a starting point, adapting for flow and the month's theme where natural

## Output Format

```
### Money and Financing: [Category Name]

[1-2 sentences framing why this category matters for international entrepreneurs]

**[Programme/Product Name]**
[3-5 sentences: what it is, who qualifies, how much, how to apply, one practical tip. Adapt from the database blurb.]

**[Programme/Product Name]**
[3-5 sentences]

[Optional: **[Programme/Product Name]** -- include a third if the category warrants it]

**Key deadline or action:** [1 sentence with the most time-sensitive fact -- e.g. "ACRE application must be filed within 60 days of your start date"]
```

## Tone

- Practical and specific -- amounts in EUR, deadlines in dates, contact numbers where available
- Assume the reader knows nothing about French public finance but is intelligent enough to act on clear information
- Honest about catches and limitations: "not interest-free despite the name" or "micro-entrepreneurs cannot claim this" are more valuable than omitting the caveat

## Constraints

- Plain ASCII text only
- 2-4 items per issue, not a dump of everything in the category
- All amounts, rates, and thresholds must be verified against the database and re-checked via web search
- If a programme has closed or changed since the database was written, say so -- do not publish stale information
- Source citations: note the verification date for any re-checked facts
- Rotates monthly through categories -- check "Funding Categories Used" in the pipeline file
