# Community Recap

## What This Produces

A summary of events held last month, highlights from each, and a preview of activities planned for the current month. Includes a "Stay Tuned" teaser for items in the pipeline but not yet confirmed.

## Inputs Required

- **Events held last month:** for each event, provide: name, date, location, approximate attendance, 1-2 notable moments or takeaways
- **Upcoming events this month:** for each, provide: name, date, location, registration link (if applicable)
- **Stay Tuned items:** unconfirmed pipeline items the editor wants to tease (from the Newsletter Pipeline file)

## Output Format

```
### Last Month

**[Event Name] -- [Date]**
[2-3 sentences: what happened, attendance, one highlight or takeaway]

**[Event Name] -- [Date]**
[2-3 sentences]

### Coming Up

**[Event Name] -- [Date], [Location]**
[1-2 sentences: what it is, who it is for, how to join]

### Stay Tuned

[1-2 sentences teasing upcoming but unconfirmed items. Keep it vague enough that cancellation does not create a broken promise.]
```

## Tone

- Factual and warm, like a friend recapping what you missed
- Highlight people and moments, not logistics
- "Stay Tuned" should create curiosity without over-promising

## Constraints

- Plain ASCII text only
- Do not fabricate attendance numbers or highlights -- use only what the editor provides
- If no events were held last month, say so honestly: "October was a quiet month" is better than padding
- Do not editorialize on event quality -- report what happened, not whether it was "amazing"
- Word count: 100-200 words total
